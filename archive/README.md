# KAPSHI Project Archive

This directory stores original reference materials, transcripts, and raw extraction artifacts preserved outside the production build.

## Structure:
- `reference-notes/`: Transcripts and slide narrative notes extracted from presentations, heritage research, and the 3-minute video strategy.
- `extracted-raw/`: Raw asset extraction dumps from PPTX and PDF source decks, plus uncompressed scratch media.

All curated, production-approved assets reside in `public/assets/`.
